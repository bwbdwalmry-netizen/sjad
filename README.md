# تطبيق سجاد — بطاقة ولاء مغسلة سجاد

بطاقة ولاء رقمية كاملة: العميل يمسح باركودًا واحدًا لأول مرة فقط، وتحصل على إشعارات الاقتراب (500م)
والتذكير الأسبوعي، والموظف يضيف الأختام بمسح باركود البطاقة.

---

## 1) المتطلبات

- استضافة تدعم **PHP 8+** مع إضافة `pdo_sqlite` (متوفرة افتراضيًا لدى معظم الاستضافات مثل cPanel).
- لا تحتاج Node.js ولا قاعدة بيانات MySQL — البيانات في ملف SQLite يُنشأ تلقائيًا.
- دومين + HTTPS (لازم للكاميرا والإشعارات والموقع الجغرافي).

## 2) التركيب (5 دقائق)

1. عدّل `config.php`:
   - `shop_name` — اسم مغسلتك.
   - `geo_lat` / `geo_lng` — إحداثيات المغسلة من خرائط جوجل (اضغط زر الماوس الأيمن على موقعك → الإحداثيات).
   - `geo_radius_m` — النطاق (الافتراضي 500 متر).
   - `staff` — **غيّر اسم المستخدم والرمز السري فورًا**.
   - `goal_stamps` — عدد الأختام للمكافأة (الافتراضي 8).
2. ارفع كل الملفات إلى مجلد مثل `public_html/sajad/`.
3. افتح `https://your-domain.com/sajad/` — يعمل فورًا (تُنشأ قاعدة البيانات تلقائيًا في `data/`).

## 3) باركود المغسلة (لإنشاء حساب العميل)

- باركود العميل يشير دائمًا إلى: `https://your-domain.com/sajad/new.php`
- اطبع QR من أي مولّد مجاني لهذا الرابط (الملف `qr/shop-qr.png` نموذج جاهز — أعد توليده بالرابط الحقيقي).
- أول مسح → ينشئ حسابًا برقم بطاقة مثل `SJ-4821` ويحفظه على جهاز العميل.
- **لا تسجيل ولا كلمة مرور** — إذا فتح العميل الرابط لاحقًا من نفس الجهاز تظهر بطاقته مباشرة.

## 4) صفحة الموظف

- `https://your-domain.com/sajad/staff.php`
- دخول بالاسم والرمز من `config.php` → تُفتح الكاميرا → وجّهها على باركود بطاقة العميل
  (مع بحث يدوي بالرقم كاحتياط).
- زر «إضافة ختم» يزيد الختم؛ عند اكتمال العدد تُصرف المكافأة تلقائيًا وتبدأ بطاقة جديدة،
  ويصل العميل إشعار «مبروك!».

## 5) الإشعارات (OneSignal — مجاني)

1. أنشئ حسابًا على onesignal.com → New App → Web → أدخل دومينك.
2. ضع `onesignal_app_id` و `onesignal_rest_key` في `config.php`.
3. الإشعارات تعمل تلقائيًا:
   - **التذكير الأسبوعي**: من cPanel → Cron Jobs: `0 12 * * 5` على `cron/weekly.php` (كل جمعة 12 ظهرًا — عدّل الوقت/اليوم كما تشاء).
   - **تذكير الاقتراب 500م**: يُفحص الموقع عند فتح البطاقة، ويُرسل إشعارًا عند دخول النطاق (بفاصل `geo_cooldown` ساعة بين التكرار).

## 6) ملاحظة مهمة عن تنبيه 500م في الخلفية

متصفحات الويب (حتى مع PWA) لا تتيح تتبع الموقع باستمرار والتطبيق مغلق — لذلك:
- أثناء فتح البطاقة: فحص فوري + إشعار.
- للتنبيه **والتطبيق مغلق تمامًا**: غلّف نفس الكود بتطبيق أصلي عبر **Capacitor** (نفس ملفات PHP
  تبقى كما هي؛ فقط يُضاف مشغّل أصلي يستخدم Geofencing API). يمكن تنفيذه لاحقًا بنفس قاعدة البيانات.

## 7) الأمان

- رابط البطاقة يحمل توكنًا عشوائيًا 32 بايت لا يُخمَّن — من فقد جهازه يمسح الباركود من جديد.
- ملفات `config.php` و `db.php` وقاعدة البيانات محمية عبر `.htaccess`.
- صفحة العميل للعرض فقط — كل التعديل تمر عبر `api.php` مع تحقق التوكن أو جلسة الموظف.

## بنية الملفات

```
sajad/
├── config.php          # الإعدادات (عدّله أولًا)
├── db.php              # تهيئة SQLite + دوال المسافة والإشعارات
├── api.php             # كل واجهات الـ JSON
├── new.php             # رابط باركود المغسلة (إنشاء بطاقة)
├── index.php           # بطاقة العميل (PWA)
├── staff.php           # لوحة الموظف مع الماسح
├── sw.js, manifest.webmanifest
├── assets/css, assets/js
├── cron/weekly.php     # التذكير الأسبوعي
└── data/               # قاعدة البيانات (تُنشأ تلقائيًا)
```
